# Direction artistique — Garage Sport Auto (site 16)

**Angle** : le devis transparent — fiche d'intervention d'atelier, vue éclatée de pièces façon plan technique, bon de commande carbone.

## Palette
| Rôle | Hex |
|---|---|
| Anthracite (texte, sections pleines) | `#2A2D31` |
| Blanc (fond) | `#FFFFFF` |
| Papier fiche (fond secondaire) | `#F2F2EE` |
| Orange atelier (aplats, CTA avec texte anthracite) | `#E2601B` |
| Orange foncé (texte orange sur blanc, AA) | `#AE4510` |
| Bleu plan technique (traits des dessins uniquement) | `#3D6E9E` |

## Polices
- Titres : **Chakra Petch** 600/700 (`@fontsource/chakra-petch`)
- Texte : **Red Hat Text** variable (`@fontsource-variable/red-hat-text`) — IBM Plex Sans est déjà prise par Garage Universel (lot 1).

## Structure de l'accueil
1. Hero en deux colonnes : à gauche le titre « Votre garage de quartier à Groslay », 4,3/5, Demander un devis + Appeler, statut ; à droite un **en-tête de fiche d'intervention** (N° de fiche, cases à cocher Mécanique / Carrosserie / Peinture, zone « Constat »).
2. Services en liste numérotée de fiche (codes d'opération, pas de cartes).
3. « On ne change que ce qui doit l'être » : **vue éclatée SVG du pot d'échappement** (traits bleu plan, repères numérotés) + l'histoire de l'avis.
4. Pros & flottes, **formulaire de devis = fiche d'intervention carbone**, point relais, avis, infos.

## Élément signature
Dessin technique éclaté + formulaire de devis en fiche d'intervention.

## Ce qui le distingue
Seul site « plan technique » orange / anthracite. Diffère de Garage 2000 (laque noire, chrome, rouge vernis, nuancier peinture) et des garages du lot 1 (jaune signalisation, casiers kraft, carnet d'entretien).
